# Portfolio Website

A responsive portfolio website based on the supplied resume.

## Features
- Black / white / light-violet visual system
- Dark / light theme toggle
- Interactive Three.js 3D Sentinel-X rescue robot model with smooth drag rotation, damping and zoom
- Drag to rotate, mouse wheel/pinch to zoom, with smooth inertia/damping
- Responsive mobile layout
- Personal name included; phone number excluded
- No external JavaScript framework required

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
